## Objetivo

Este documento reúne os principais requisitos funcionais identificados para a primeira versão do sistema.

Os requisitos funcionais descrevem **as funcionalidades que o sistema deverá oferecer aos seus utilizadores**, servindo como guia para o desenvolvimento e para a evolução da aplicação.

À medida que novas necessidades forem identificadas, este documento poderá ser atualizado.

---

# Gestão de Óticas

O sistema deverá permitir:

- cadastrar uma ótica;
- editar os dados de uma ótica;
- inativar uma ótica;
- consultar as óticas às quais o utilizador possui acesso.

---

# Gestão de Utilizadores

O sistema deverá permitir:

- cadastrar um utilizador;
- editar os dados de um utilizador;
- associar um utilizador a uma ou mais óticas;
- definir o papel de um utilizador em cada ótica;
- remover um utilizador de uma ótica.

---

# Gestão de Clientes

O sistema deverá permitir:

- cadastrar clientes;
- editar clientes;
- consultar clientes;
- inativar clientes.

---

# Gestão de Receitas

O sistema deverá permitir:

- registrar receitas;
- consultar o histórico de receitas de um cliente;
- associar uma receita a uma venda.

---

# Gestão de Produtos

O sistema deverá permitir:

- cadastrar produtos;
- editar produtos;
- consultar produtos;
- inativar produtos.

---

# Gestão de Compras

O sistema deverá permitir:

- registrar compras junto a fornecedores;
- adicionar produtos às compras;
- alterar o estado de uma compra;
- consultar compras realizadas.

---

# Gestão de Vendas

O sistema deverá permitir:

- criar vendas;
- adicionar produtos a uma venda;
- associar uma receita quando necessário;
- registrar as informações técnicas da lente;
- associar tratamentos às lentes;
- registrar pagamentos;
- finalizar uma venda;
- cancelar uma venda;
- consultar vendas realizadas.

---

# Gestão de Pagamentos

O sistema deverá permitir:

- registrar pagamentos;
- registrar pagamentos parciais;
- registrar o pagamento restante de uma venda;
- consultar pagamentos realizados.

---

# Funcionalidades Futuras

As funcionalidades abaixo foram identificadas durante a modelagem do domínio, mas não fazem parte da primeira versão do sistema.

O sistema poderá futuramente permitir:

- registrar movimentações de estoque;
- controlar níveis mínimos de estoque;
- emitir relatórios financeiros;
- emitir relatórios de vendas;
- enviar lembretes para realização de novos exames de vista;
- enviar notificações por e-mail aos clientes;
- disponibilizar um painel (dashboard) com indicadores da ótica.

---

# Observações

- Este documento representa o levantamento inicial dos requisitos funcionais.
    
- Novas funcionalidades poderão ser adicionadas conforme a evolução do domínio.
    
- Os requisitos descrevem apenas o comportamento esperado do sistema.
