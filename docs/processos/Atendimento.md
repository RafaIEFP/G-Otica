# Atendimento ao Cliente

## Objetivo
Descrever o fluxo de atendimento realizado na ótica desde a chegada do cliente até o início de uma venda.

---

## Participantes
* Cliente
* Vendedor

---

## Fluxo Principal

1. O cliente chega à ótica.
2. O vendedor identifica o cliente.
3. Caso o cliente ainda não esteja cadastrado, realiza seu cadastro.
4. O vendedor verifica se existe uma receita válida.
5. O cliente informa sua necessidade.
6. O vendedor orienta a escolha dos produtos mais adequados.
7. Caso o cliente decida realizar uma compra, inicia-se o processo de venda.

---

## Fluxos Alternativos

### Cliente sem receita
O cliente poderá ser orientado a realizar um exame de vista antes da compra de lentes corretivas.

### Compra sem lentes
Caso a venda envolva apenas armações ou acessórios, não será necessário utilizar uma receita.

---

## Resultado

O cliente encontra-se identificado e apto para iniciar uma venda.
