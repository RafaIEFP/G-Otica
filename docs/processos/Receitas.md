# Processo de Utilização da Receita

## Objetivo

Descrever como a receita oftalmológica é utilizada durante uma venda.

---

## Participantes
* Cliente
* Vendedor

---

## Fluxo Principal
1. O cliente apresenta uma receita.
2. O vendedor verifica sua validade.
3. A receita é associada à venda.
4. As informações da receita são utilizadas para definição das lentes.
5. O vendedor realiza novamente as medições de DP e DNP, quando necessário.
6. As medidas e demais características da lente são registradas para fabricação.

---

## Fluxos Alternativos

### Nova receita
Caso o cliente realize um novo exame, uma nova receita será cadastrada no sistema.

As receitas anteriores permanecem armazenadas para consulta.

---

## Resultado

A venda passa a possuir todas as informações necessárias para a fabricação correta das lentes.
