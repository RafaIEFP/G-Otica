# Processos de Negócio

Esta pasta documenta os principais processos de negócio identificados durante o levantamento de requisitos da aplicação.

Enquanto a pasta `domain` descreve os conceitos do domínio e a pasta `architecture` registra as decisões de modelagem, esta documentação apresenta **como as atividades da ótica acontecem na prática**.

Cada processo descreve o fluxo de trabalho realizado pelos profissionais da ótica, servindo como referência para o desenvolvimento das funcionalidades do sistema.

## Estrutura dos documentos
Todos os processos seguem uma estrutura semelhante.

### Objetivo
Descreve a finalidade do processo.

### Participantes
Apresenta os atores envolvidos.

### Fluxo Principal
Descreve o funcionamento normal do processo.

### Fluxos Alternativos
Registra situações especiais ou exceções.

### Resultado
Apresenta o estado esperado após a conclusão do processo.

---

Os processos documentados representam o funcionamento atual da ótica e poderão evoluir conforme novas regras de negócio forem identificadas.
